# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately, either through GitHub's
[Report a vulnerability](https://github.com/BlackDuckyGB/MyBuoy/security/advisories/new)
form or by writing to **security@golden-block.fr**, with:

- a description of the problem and its impact,
- the steps to reproduce it,
- the MyBuoy version and the Android version you used.

You will get an answer within a week. Once the problem is fixed, the release
notes will mention it, and credit you if you wish.

## Supported versions

Only the latest release published on GitHub is supported. Please check that
the problem still happens with it before reporting.

## Scope

MyBuoy has no account and collects no personal data (see
[PRIVACY.md](PRIVACY.md)). Relevant reports are, for instance, a way to make
the app crash or misbehave with crafted map, tide or shared-link data, or a
way for another app to read MyBuoy's private files.
